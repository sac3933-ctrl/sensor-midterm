# 센서 핵심노트

「센서 및 응용」 나만의 학습 바이블 웹앱입니다. 0편 기초 도구부터 4편 현업 연결까지 26개 장.
각 장마다 용어(일반·전공·쉽게 보기), 단위 읽는 법, 공식, 그림·애니메이션, 숫자가 바뀌는 문제(상세 풀이 + fx-570ES PLUS 입력 순서), 암기 카드가 있어요.

- 휴대폰에서 열고 「홈 화면에 추가」하면 앱처럼 쓸 수 있어요 (한 번 열면 오프라인에서도 열림).
- 내 노트·사진·카드는 이 기기에 저장돼요. 노트 화면의 백업 버튼으로 파일로 내보낼 수 있어요.
